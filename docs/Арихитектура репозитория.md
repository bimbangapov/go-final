## Описание
Документ описывает орхитектуру репозитория проекта. 
Пакеты содержащиеся в проекте и их содержание

## Список пакетов/директорий проекта
* docs - директория в которой собрана документация по проекту 
* logs - директория в которой хранится файл логов. Директория и файл логов инициализируется в момент запсука проекта. При повторных запусках
запись логов продолжается в существующий файл
* pkg - директория пакетов проекта
  * api - пакет в котором описываются функции с помощью которых реализованы api методы  
  * config - пакет для определения переменных из окружения. 
  * db - пакет с функциями Базы данных 
  * server - Пакет для инициализации сервера 
* tests - Директория с тестами
* web - Директория хранящая фронтенд сервера
  * css 
  * js
