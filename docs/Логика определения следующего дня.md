# Правила повторения задач (repeat)

## Описание

Параметр `repeat` определяет периодичность выполнения задачи.

Правило используется при создании, изменении и завершении задачи,
а также при расчёте следующей даты выполнения.

## Поддерживаемые правила

| Правило | Описание | Пример |
|---------|----------|--------|
| `d N` | Повторение каждые N дней | `d 3` — каждые 3 дня |
| `y` | Повторение раз в год | `y` — ежегодно |
| `w N` | Повторение в указанные дни недели | `w 1,3,5` — понедельник, среда, пятница |
| `m N` | Повторение в указанные числа месяца | `m 1,15` — 1-го и 15-го числа |
| `m N M` | Повторение в указанные числа выбранных месяцев | `m 1,15 1,6` — 1-го и 15-го января и июня |
| `""` | Повторение отсутствует | Однократная задача |

**Обозначения:**

- `N` — число дней, дни недели или числа месяца в зависимости от правила.
- `M` — номера месяцев от 1 до 12.
- Для правила `w`: 1 — понедельник, 7 — воскресенье.
- Несколько значений перечисляются через запятую без пробелов.

## Логика расчёта следующей даты

Расчёт выполняется на основании трёх параметров:

| Параметр | Описание |
|----------|----------|
| `now` | Текущая дата |
| `date` | Исходная дата выполнения задачи |
| `repeat` | Правило повторения |

**Алгоритм:**

1. Проверяется корректность исходной даты и правила `repeat`.
2. Определяется периодичность выполнения задачи.
3. Вычисляется следующая дата согласно правилу повторения.
4. Если рассчитанная дата уже прошла, расчёт продолжается до получения подходящей будущей даты.
5. Результат возвращается в формате `YYYYMMDD`.

### Пример

**Входные параметры:**

```text
now    = 20261014
date   = 20261014
repeat = d 3
```

**Результат:**

```text
20261017
```

Следующее выполнение задачи запланировано через 3 дня.

## Завершение задачи

При вызове `POST /api/task/done` поведение зависит от значения `repeat`.

| Условие | Действие |
|---------|----------|
| `repeat` пустой | Задача удаляется из БД |
| `repeat` заполнен | Рассчитывается следующая дата, задача обновляется в БД |

> [!NOTE]
> Для повторяющихся задач сохраняется существующий идентификатор.
> Изменяется только дата следующего выполнения.
